# Universal TV Remote

Expo 58 / React Native 0.88 application foundation for a local Wi-Fi Android TV remote.

This milestone includes strict TypeScript, design tokens, navigation, storage boundaries, typed services, deterministic tests, and JavaScript CI. Native protocol implementation and complete screens follow in separate milestones. There is no hardware compatibility claim.

Use Node 24.19 and development builds. Run `npm ci`, `npm run typecheck`, `npm run lint`, `npm run format:check`, and `npm run test:coverage`. Expo Go cannot load the eventual native transport. See ARCHITECTURE.md, PROTOCOL.md, and DEVELOPMENT.md for the accepted design and gates.
